# Architecture rules

- Synchronize the dispatch theme through `useScreenTheme` for the page, app shell, and dispatch dialog; each has a separate DOM root, and the sidebar must share the console's chosen palette.
- Render the finalization dialog in a body portal above operational cards and keep its personnel pickers above the dialog overlay; card stacking contexts must not obscure closure confirmation.- Route+km data lives as static JSON copies in src/data/routes (generated by scripts/import-mop-route.py from Vialidad/MOP) and is lazy-loaded by src/lib/routeKilometer.ts; never query MOP at search time — live emergencies need instant local lookup.
